# EthioWorkforce Cloud Hosting & Live Deployment Guide

This guide details how to host EthioWorkforce on the **best 100% free cloud database and backend infrastructure**, enabling live inspection, multi-site testing, and production rollout.

---

## 🌟 The Recommended Free Architecture

| Component | Recommended Provider | Free Tier Allowance | Why It's The Best |
| :--- | :--- | :--- | :--- |
| **PostgreSQL Database** | **[Neon](https://neon.tech)** (or Supabase) | 0.5 GB storage, serverless autoscaling, SSL encryption | **Never auto-deletes** after 30 days (unlike Render's internal free DB). Instant setup, built-in SQL web console for inspecting data. |
| **FastAPI Backend** | **[Render](https://render.com)** (or Koyeb) | 750 free hours/month (24/7), free SSL, automatic git deployments | Zero-config deployment via `render.yaml`, automatic HTTPS (`https://*.onrender.com`), native Python 3.11 runtime. |
| **Frontend Web App** | **[Vercel](https://vercel.com)** or **GitHub Pages** | Unlimited free bandwidth & global CDN | Run the Flutter web build directly in any desktop/mobile browser without requiring APK installation. |
| **24/7 Keep-Warm** | **[UptimeRobot](https://uptimerobot.com)** | 50 free monitors (5-minute interval) | Eliminates free-tier cold starts by pinging the `/health` endpoint every 14 minutes. |

## Step 1: Provision the Free PostgreSQL Database (60 Seconds)

1. Navigate to **[neon.tech](https://neon.tech)** and click **Sign Up** (Sign in with your GitHub account).
2. Click **Create Project**:
   - **Project Name**: `ethioworkforce-prod`
   - **Postgres Version**: `16`
   - **Region**: Choose Europe (`Frankfurt (eu-central-1)`) for lowest latency to Ethiopia.
3. Click **Create Project**.
4. On the project dashboard, locate the **Connection Details** box. Select **Connection string** (Pooled or Direct).
5. Copy the connection string. It will look like:
   ```text
   postgresql://ethioworkforce_owner:YourPassword@ep-cool-butterfly-123456.eu-central-1.aws.neon.tech/neondb?sslmode=require
   ```
   *(Note: EthioWorkforce automatically normalizes this connection string to use pure-Python `pg8000` with SSL).*

## Step 2: Initialize & Seed the Cloud Database

You can run migrations and create the default admin user directly from your local machine to your new Neon cloud database before deploying the backend:

In PowerShell:
```powershell
# Set the cloud database URL in your shell
$env:DATABASE_URL = "postgresql://ethioworkforce_owner:YourPassword@ep-cool-butterfly-123456.eu-central-1.aws.neon.tech/neondb?sslmode=require"

# Run the idempotent cloud initializer
cd backend
..\backend\venv\Scripts\python.exe scripts\init_cloud_db.py
```

This will:
- Run all 25+ Alembic schema migrations.
- Provision the initial Super Admin account (configured via $env:ADMIN_INITIAL_PASSWORD).
- Seed initial sites (`Bole Construction Site`, `Adama Industrial Facility`, `Headquarters`).
- Seed standard Ethiopian work types (Daily Casuals, Masons, Supervisors, Security).

## Step 3: Deploy the Backend to Render (3 Minutes)

### Option A: 1-Click Blueprint (Recommended)

1. Push your latest code to your GitHub repository:
   ```bash
   git add .
   git commit -m "Configure cloud hosting and live deployment"
   git push origin main
   ```
2. Log in to **[Render.com](https://render.com)** with your GitHub account.
3. Click **New +** → **Blueprint**.
4. Select your `EthioWorkforce` repository.
5. Render will automatically detect `render.yaml`.
6. Click **Apply**.
7. In the Web Service environment variables, set:
   - `DATABASE_URL`: *(Paste your Neon connection string from Step 1)*
   - `SECRET_KEY`: *(Auto-generated by Render)*
   - `ENVIRONMENT`: `production`
   - `ENABLE_DOCS`: `true`
   - `CORS_ORIGINS`: `["*"]`
8. Click **Deploy**.

### Option B: Manual Web Service Setup
1. Click **New +** → **Web Service**.
2. Connect your GitHub repository.
3. Configure settings:
   - **Name**: `ethioworkforce-api`
   - **Region**: Frankfurt (EU Central)
   - **Branch**: `main`
   - **Runtime**: Python 3
   - **Build Command**: `cd backend && pip install -r requirements.txt && python scripts/init_cloud_db.py`
   - **Start Command**: `cd backend && uvicorn app.main:app --host 0.0.0.0 --port $PORT`
   - **Instance Type**: **Free**
4. Under **Advanced** → **Environment Variables**, add:
   ```text
   DATABASE_URL = postgresql://ethioworkforce_owner:YourPassword@ep-cool-butterfly-123456.eu-central-1.aws.neon.tech/neondb?sslmode=require
   SECRET_KEY = <generate a 32+ character random string>
   ENVIRONMENT = production
   ENABLE_DOCS = true
   CORS_ORIGINS = ["*"]
   ```
5. Click **Create Web Service**.

## Step 4: Verify Live Cloud Endpoints

Once Render completes the build (typically 2-4 minutes), you will receive a public HTTPS URL (e.g. `https://ethioworkforce-api.onrender.com`).

### 1. Root & Health Check
Open in your browser:
- `https://ethioworkforce-api.onrender.com/`
  ```json
  {
    "name": "EthioWorkforce API",
    "version": "1.0.0",
    "status": "operational",
    "environment": "production",
    "docs": "/api/docs",
    "health": "/health"
  }
  ```
- `https://ethioworkforce-api.onrender.com/health`
  ```json
  {"status":"healthy","service":"ethioworkforce-api"}
  ```

### 2. Live Interactive Swagger Documentation
Open in your browser:
- **`https://ethioworkforce-api.onrender.com/api/docs`**

You can test live authentication, query workers, trigger payroll calculations, and download bank reports directly from the Swagger UI.

## Step 5: Prevent Cold Starts (Free 24/7 Keep-Warm)

Render's free tier spins down after 15 minutes of inactivity. To keep your API running 24/7 with zero latency:

1. Sign up for a free account at **[UptimeRobot.com](https://uptimerobot.com)**.
2. Click **Add New Monitor**:
   - **Monitor Type**: `HTTP(s)`
   - **Friendly Name**: `EthioWorkforce Cloud Backend`
   - **URL (or IP)**: `https://ethioworkforce-api.onrender.com/health`
   - **Monitoring Interval**: `Every 14 minutes`
3. Click **Create Monitor**.
4. Your free server will now stay warm 24/7.

## Step 6: Connect the Mobile & Web App to Cloud

### Option 1: Live in App Settings
1. Open the app on your phone or browser.
2. Log in with your configured Super Admin credentials.
3. Go to **Settings** → **Backend Configuration** → **Backend API URL**.
4. Enter:
   ```text
   https://ethioworkforce-api.onrender.com/api/v1
   ```
5. Tap **Save**. The app immediately communicates with the cloud backend.

### Option 2: Pre-Configure for Release APK
In `frontend/lib/core/network/dio_client.dart`:
```dart
static const String defaultProductionUrl = 'https://ethioworkforce-api.onrender.com/api/v1';
```

Build the release APK:
```bash
cd frontend
flutter build apk --release
```
The APK at `frontend/build/app/outputs/flutter-apk/app-release.apk` is now ready for distribution to market users and site supervisors.
